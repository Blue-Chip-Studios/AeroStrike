# UI references

Reference screenshots for AeroStrike's UI design system (BCDK-Build-Game Phase 3: "UI references supplied").

| File | Screen | What to take from it |
| --- | --- | --- |
| `01-team-select.webp` | Pick your side (Blue vs Red) | Team panels, base-health bars, pilot/jet/score roster, condensed uppercase type, join/balancing buttons |
| `02-hangar-daily-reward.webp` | Hangar + daily reward modal | Top nav bar, currency display, aircraft list by tier, spec bars with upgrade costs, hazard-stripe framing, 7-day reward track, Launch CTA |
| `03-hud-concept-cockpit.jpg` | Cockpit HUD (concept art) | Green HUD speed/altitude tapes, lock box, missile warnings, G meter, fuel bar, mobile touch buttons |
| `04-hud-concept-third-person.jpg` | Third-person HUD (concept art) | Same HUD language in chase cam, G-force meter, fuel/afterburner gauge, ammo panel, mobile button cluster |
| `05-changelog-modal.webp` | Update / changelog modal | Two-column modal, NEW/IMPROVED tags, icon + heading + body rows, primary CTA |
| `06-in-flight-hud.webp` | In-game flight HUD (mobile) | Team score/timer bar, objective strip, throttle/afterburner bar, gun/missile circular buttons, weapon slots (AA/AG), auto-rearm, target box |
| `07-kill-cam.webp` | Kill cam | Letterbox bars, kill feed line, "shot down by" card with level badge, aircraft and weapon, skip button |

`03` and `04` are concept renders (target look); the others are in-game captures. Player names in the captures are incidental.
